# مساعد البيت — بوت واتساب للمهام المنزلية

بوت واتساب يدير مهام العاملة المنزلية والسائق: قائمة مهام صباحية بأزرار، طلبات فورية من أهل البيت، قائمة مشتريات، تذكيرات، تقييم بالوجوه مع ملاحظات، وملخص مسائي. يعمل بالكامل على Cloudflare Workers (مجاني للاستخدام المنزلي) بلا خادم تديره.

## المكونات

| الملف | الدور |
|---|---|
| `src/worker.js` | المدخل: يستقبل Webhook من Meta، ويخدم صفحة الإدارة، ويشغّل الدورة الزمنية كل 5 دقائق |
| `src/ledger.js` | «الدفتر»: كائن Durable Object بقاعدة SQLite يحوي كل البيانات وكل منطق البوت |
| `src/wa.js` | استدعاءات WhatsApp Cloud API |
| `src/templates.js` | القوالب السبعة (تُنشأ من صفحة الإدارة) |
| `src/parse.js` | فهم الأوامر العربية القصيرة («دوري: … كل خميس 9 ص») |
| `src/admin_ui.js` | صفحة الإدارة للجوال |

## النشر (من الجوال)

1. لوحة Cloudflare ← **Workers & Pages** ← **Create** ← **Import a repository** ← اربط GitHub واختر `mudaar-bot` ← Deploy.
2. بعد أول نشر: **Settings → Variables and Secrets** وأضف كـ *Secret*:
   - `WHATSAPP_TOKEN` — المفتاح الدائم من مستخدم النظام
   - `PHONE_NUMBER_ID` — معرّف الرقم
   - `WABA_ID` — معرّف حساب واتساب للأعمال (Messaging account)
   - `ADMIN_PASSWORD` — كلمة مرور صفحة الإدارة
   - اختياري: `APP_ID` و`APP_SECRET` (لضبط Webhook تلقائياً والتحقق من التوقيع)، `VERIFY_TOKEN` (افتراضيه `mudaar-verify-2026`)
3. افتح `https://<اسم-الووركر>.<حسابك>.workers.dev/admin` واتبع خطوات صفحة **الإعداد** بالترتيب: الرقم ← Webhook ← الاشتراك ← القوالب ← رسالة تجريبية.
4. أضف الأشخاص (ربّ البيت أولاً، ثم العاملة والسائق) والمهام الدورية.

أي تعديل يُدفع إلى الفرع `main` يُنشر تلقائياً.

## التكلفة

Cloudflare: الخطة المجانية تكفي (Workers + Durable Objects SQLite + Workers AI للترجمة). واتساب: الرسائل داخل نافذة 24 ساعة مجانية حتى 1,000 شهرياً لكل رقم، والقوالب خارجها نحو 0.04 ريال للرسالة.

## ملاحظات تقنية

- المنطقة الزمنية ثابتة على الرياض (`TIMEZONE_OFFSET_MINUTES=180`).
- الدورة الزمنية (`*/5 * * * *`) تنشئ مهام اليوم بعد منتصف الليل، وترسل كل مهمة في وقتها، وترسل المشتريات والملخص في مواعيدهما، وتتابع التذكيرات.
- الرسائل الحرة تُستخدم عندما يكون المستلم قد راسل البوت خلال 24 ساعة، وإلا تُستخدم القوالب المعتمدة بالأزرار نفسها.
